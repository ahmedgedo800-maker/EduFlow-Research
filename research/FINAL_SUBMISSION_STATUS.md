# EduFlow Research Project — Submission Status

## Project
**Optimizing Web Application Performance Using Modern Web Development Techniques: An Experimental Study**

## Current evidence
The baseline version (V0) was actually measured with Lighthouse on the local EduFlow application.

- Performance: **57**
- First Contentful Paint (FCP): **8.5 s**
- Largest Contentful Paint (LCP): **15.1 s**
- Total Blocking Time (TBT): **60 ms** (one run was observed at 50 ms; Lighthouse values can vary)
- Cumulative Layout Shift (CLS): **0**
- Speed Index: **8.5 s**

A screenshot of the Lighthouse report is included in `evidence/V0_Lighthouse_Performance.png`.
