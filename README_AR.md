# ملف التسليم — EduFlow

ده مشروع React/Vite خاص بدراسة أداء تطبيقات الويب.

### تشغيل المشروع
1. افتح CMD داخل مجلد `eduflow-app`.
2. نفذ:
   `npm install`
3. ثم:
   `npm run dev`
4. افتح الرابط الذي يظهر لك.

### الموجود داخل الملف
- التطبيق كامل.
- خطة البحث.
- مسودة البحث.
- نتائج V0 الحقيقية من Lighthouse.
- صورة إثبات للنتيجة.
- نسخة V0 ونسخة V1 من الكود.
- ملفات تنظيم التجربة.

**مهم:** لم يتم اختلاق أرقام للنتائج. أي نتائج إضافية يجب أن تأتي من قياس فعلي.
