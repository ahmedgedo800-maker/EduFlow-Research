# Experiment Checklist
## Before testing
- Same browser/version
- Same viewport
- Same test page
- Same network profile
- Close unrelated tabs/apps
- Use production build when appropriate
- Do not change unrelated content between versions

## Each version
- Run Lighthouse at least 3 times
- Record every run
- Calculate median
- Save reports/screenshots
- Note unusual results

## Final
- Compare V0 with V1–V5
- Calculate percentage improvements
- Identify strongest technique
- Discuss trade-offs
- Write Results/Discussion from measured data only
